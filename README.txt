MY SPACE — CONSOLIDATED RELEASE

Upload these three files to the ROOT of your existing GitHub Pages repository:
- index.html
- manifest.json
- sw.js

FEATURES
- Visual two-column image/document library
- In-app image and PDF preview
- Quick notes (note text + optional tags)
- Image/PDF title, note and optional tags
- Basic local filename-based tag suggestions (not AI/OCR)
- Save website links
- Search across titles, notes, filenames, URLs and tags
- Favourites and pinned items
- Spaces based on matching tags
- Serendipity random rediscovery
- Password-encrypted backup and restore, including attachments and Spaces
- PWA app-shell caching

PUBLISH
1. Download and extract this ZIP in iPhone Files.
2. Open your EXISTING GitHub repository in Safari.
3. Choose Add file > Upload files.
4. Select index.html, manifest.json and sw.js from the extracted folder.
5. Commit changes. If GitHub asks to confirm replacing existing files, confirm.
6. Wait for GitHub Pages deployment, then close and reopen the website in Safari.

IMPORTANT
- Do not delete or recreate the repository.
- Do not clear Safari website data.
- Back up existing content before updating.
- Never upload personal notes, photos, PDFs or backups to the public GitHub repository.
- Personal items stay in local browser storage on this device; no automatic sync.
- Smart suggestions currently use filenames and file types only. OCR, semantic search and AI understanding are not implemented in this release.
- Browser storage may be lost if Safari website data is cleared or evicted. Keep encrypted backups in iCloud Drive.
- Test restore before relying on backups for important records.
